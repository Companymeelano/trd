# میلانو تریدینگ اینتلیجنس — Meelano Trading Intelligence v5

> طراحی و توسعه: **Milad Yaghoobi** · **Meelano Studio Design**
> بات هوشمند ترید و بررسی کریپتو — نسخهٔ ۵٫۱ (APEX TRADER+)

سامانهٔ تحلیل و سیگنال کریپتو با معماری «قیف تصمیم نهادی»:
دادهٔ زندهٔ Binance/CoinGecko → تشخیص رژیم بازار → ۱۵ فیلتر هم‌گرایی وزن‌دار →
تأیید چند تایم‌فریمی (1h/4h/1d) → اجماع چندمدلی هوش مصنوعی → دروازهٔ رژیم بیت‌کوین →
پلن ریسک ساختاری → درجه‌بندی کیفیت (A+/A/B/C) → خنک‌کردن تکرار.

📄 برای معماری کامل، فرمول‌ها و سند مهندسی: **[ANALYSIS.md](ANALYSIS.md)**

## استقرار روی هاست cPanel

1. کل محتوای مخزن را در `public_html/trader` آپلود کنید (`.htaccess` همراه است).
2. `settings.php` را باز کنید (رمز پیش‌فرض `meelano-admin`) و **فوراً رمز را تغییر دهید**.
3. تب «پایگاه‌داده»: host=`localhost`، اطلاعات دیتابیس cPanel را وارد و «تست اتصال» و سپس «ساخت جداول» بزنید.
4. تب «هوش مصنوعی»: کلیدهای نو را وارد کنید، «تست همه کلیدها» و سپس «انتخاب هوشمند خودکار».
5. تب «موتور سیگنال»: آستانه‌ها، فیلترهای مشتقات/سنتیمنت، وکیل مدافع و دروازهٔ پرتفوی را تنظیم کنید.
6. برای داوری خودکار سیگنال‌ها، یک کران ساعتی روی `api/tracker.php?action=run&key=کلید` بگذارید (کلید در تب امنیت).
6. نیازمندی: PHP ≥ 7.4 + افزونه‌های `curl, pdo_mysql (یا pdo_sqlite), mbstring, openssl`.

## امنیت

- کلیدهای API فقط سمت سرور و **رمزنگاری‌شده (AES-256-GCM)** در `config/settings.php` (خارج از گیت) نگهداری می‌شوند.
- `config/`, `includes/`, `storage/`, `tools/`, `tests/` با `.htaccess` از دسترسی مستقیم وب مسدودند.
- ورود مدیر + CSRF + محدودسازی نرخ + سرصفحه‌های امن روی همهٔ نقاط پایان.
- ممیزی کامل تغییرات در جدول `settings_audit` و کارنامهٔ اجرای AI در `ai_runs`.
- **هشدار:** هر کلیدی که قبلاً در چت/ایمیل/ZIP رد و بدل شده «لو رفته» است — همه را باطل (Revoke) و دوباره صادر کنید.

## اندروید

بستهٔ `android/` یک WebView امن تمام‌صفحه است (پکیج `ir.meelano.trader`):
- دانلود فایل‌ها با DownloadManager سیستم
- لینک‌های خارجی/تلگرام/ایمیل در مرورگر باز می‌شوند (ضد فیشینگ)
- Safe Browsing گوگل + SSL اجباری + صفحهٔ خطای فارسی با «تلاش دوباره»
- اسپلش برندینگ و آیکون تطبیقی سه‌بعدی در همهٔ چگالی‌ها

ساخت APK از طریق GitHub Actions (گزینهٔ «Android APK») → انتشار خودکار در Release با لینک مستقیم نصب.
